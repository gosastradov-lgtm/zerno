# ☕ Zerno — Веб-платформа specialty-кофейни

Профессиональное полнофункциональное веб-приложение для сети кофеен и ресторанов Zerno, созданное с фокусом на премиальный **UI/UX дизайн**, глубокое изучение и практическое применение **мультиязычной серверной архитектуры (C#, C++, 1C:Предприятие, JavaScript, Python)** и **реляционной базы данных (SQLite)**.

---

## 🎯 Цели и задачи проекта

### Цель
Создание законченного enterprise-решения кофейни, объединяющего современный клиентский опыт (drag-and-drop кастомизация, интерактивное меню, быстрый чекаут), соответствие законодательству РФ (54-ФЗ фискализация чеков), синхронизацию с ресторанными учетными системами (1C:Предприятие) и математические модули оптимизации и расчета лояльности на компилируемых языках (C#, C++).

### Решенные задачи:
1. **Анализ предметной области кофейного бизнеса**:
   - Технологические карты приготовления напитков (эспрессо, фильтр Batch Brew, рафы, альтернативное молоко, деградация молочной пены при перегреве выше 68°C).
   - Требования Федерального закона 54-ФЗ «О применении контрольно-кассовой техники» (ФД, ФПД, ЗН ККТ, QR-код для верификации в мобильном приложении ФНС России).
   - Складской и кассовый обмен в ресторанных сетях по стандартам **CommerceML 2.09** и **1C:EnterpriseData**.
2. **Проектирование и реализация базы данных (SQLite)**:
   - 8 связанных таблиц: `users`, `categories`, `products`, `orders`, `order_items`, `blog_posts`, `stickers`, `cup_designs`.
   - Подготовленная база данных с 26 позициями меню, 4 статьями блога, 8 авторскими SVG-стикерами и историей заказов за 7 дней.
3. **Разработка фронтенда (JavaScript / CSS3 / HTML5 / Chart.js)**:
   - Точная передача дизайн-кода **chashkacoffee.ru**: фирменная теплая льняная гамма (`--canvas: #f1f0eb`, `--paper: #fcfbf8`), акцентный темный хвойный (`--moss: #293b30`), лаймовые бейджи (`--lime: #bdd65a`), радиусы скругления `22px` и типографика **Montserrat**.
   - Плавающий фирменный хедер-пилюля.
   - **Интерактивная Drag-and-Drop студия стикеров** на стаканчике.
   - Модальные модификаторы напитков (овсяное, миндальное, кокосовое молоко, сиропы, температура).
   - Страница аналитики с интерактивными графиками **Chart.js 4**.
4. **Разработка бэкенда (Python FastAPI)**:
   - Асинхронная REST API архитектура.
   - Безопасная аутентификация на основе HMAC-SHA256 токенов и разделения ролей (`customer`, `admin`).
   - Модули CRUD для товаров, блога, статусов заказов.
5. **Мультиязычная интеграция (C#, C++, 1C)**:
   - **C# .NET Engine** (`FiscalEngine.exe`): скомпилирован на Windows, выполняет криптографический расчет фискальных признаков и расчет прогрессивной скидочной матрицы.
   - **C++17 Engine** (`queue_optimizer.cpp`): дискретный планировщик очереди бариста с сохранением температуры напитков.
   - **1C:Предприятие 8.3 XML**: экспорт каталога (CommerceML 2.09) и чеков (EnterpriseData).

### 1. Язык C# (.NET Framework CLR)
* **Файл**: `csharp_engine/FiscalEngine.cs` -> `csharp_engine/FiscalEngine.exe`
* **Роль**: Высокопроизводительный финансовый модуль:
  - Расчет прогрессивных уровней лояльности: «Гость» (0%), «Любитель кофе» (5%), «Кофейный гурман» (10%), «Золотой бариста» (15%).
  - Расчет промокодов (`ZERNO10`, `CHASHKA`, `WELCOME`).
  - Генерация криптографических фискальных реквизитов 54-ФЗ (ФД, ФПД, ЗН ККТ, РН ККТ, НДС 20%).
* **Компиляция**: Скомпилирован штатным компилятором `csc.exe` (`build.bat`).

### 2. Язык C++ (C++17 / C++20)
* **Файлы**: `cpp_engine/queue_optimizer.h`, `cpp_engine/queue_optimizer.cpp`
* **Роль**: Алгоритмический планировщик заказов в часы пиковой нагрузки:
  - Минимизация деградации микропены и крема эспрессо (Freshness Penalty Curve).
  - Балансировка заказов между станциями эспрессо, фильтр-бара и подогрева выпечки.
  - Интегрирован в админ-панель: кнопка «⚡ Запустить C++» наглядно рассчитывает время ожидания и % свежести напитка.

### 3. Платформа 1С:Предприятие 8.3
* **Файл**: `backend/one_c_service.py`
* **Роль**: Двусторонний обмен данными с типовыми конфигурациями («1С:Управление торговлей», «1С:Общепит», «1С:Розница»):
  - **CommerceML 2.09**: Выгрузка иерархического каталога, групп, товаров, цен, остатков и единиц измерения.
  - **EnterpriseData**: Выгрузка документов «ЧекККМ» со ставками НДС, кассиром, номерами смен и безналичными оплатами.
  - Кнопки экспорта вынесены в панель администратора с мгновенным скачиванием `.xml`.

### 4. Язык JavaScript & Современный Frontend
* **Файлы**: `static/js/app.js`, `catalog.js`, `stickers.js`, `cart.js`, `blog.js`, `analytics.js`
* **Роль**: Интерактивность Single Page Application:
  - Нативная реализация Drag-and-Drop (API `DragEvent` + Pointer Events для тач-устройств).
  - Динамическое построение графиков Chart.js (линейный тренд выручки за неделю, круговая диаграмма категорий, столбчатая гистограмма пиковых часов).
  - Термопечать чеков с векторным SVG QR-кодом для ФНС.

## 📦 Функционал системы

### Для Покупателя / Гостя:
1. **Каталог товаров**:
   - Фильтрация по категориям (Кофе, Авторские напитки, Холодные, Десерты, Завтраки, Чай, Зерно).
   - Полнотекстовый живой поиск по названию и описанию.
   - Фильтрация по бейджам («Хит», «Specialty», «Новинка», «Сезонное»).
   - Модальное окно модификаторов: выбор молока (овсяное, миндальное, кокосовое, безлактозное), авторских сиропов и температуры подачи (горячий / со льдом).
2. **Интерактивная Drag-and-Drop Студия Стикеров**:
   - Реалистичный векторный стаканчик Zerno с крышкой и крафтовым манжетом.
   - Перетаскивание стикеров мышью на стакан.
   - Поворот стикера (слайдер от -90° до +90°).
   - Масштабирование стикера (слайдер от 0.6x до 1.5x).
   - Удаление стикеров по отдельности или очистка всего стаканчика.
   - Выбор цвета стаканчика и крышки.
   - Нанесение имени гостя на манжет стаканчика.
   - Кнопка «Применить к заказу» — прикрепляет кастомный стаканчик к позиции корзины!
3. **Корзина и Оформление заказа**:
   - Изменение количества (+/-), удаление позиций.
   - Ввод промокодов (`ZERNO10`, `ZERNO`, `WELCOME`).
   - Мгновенный расчет скидки через **C# .NET FiscalEngine**.
   - Выбор формата («С собой», «В зале», «Доставка»).
4. **Генерация 54-ФЗ чека**:
   - Оформление заказа формирует полноценный кассовый чек с реквизитами ООО «Зерно» (г. Новосибирск, ИНН, ЗН ККТ, ФД, ФПД).
   - Векторный QR-код для верификации в приложении ФНС России.
   - Кнопка печати (оптимизирована под термопринтеры 80мм).
   - Кнопка скачивания чека в формате `.txt`.
5. **Журнал Zerno (Блог)**:
   - Статьи об обжарке зерна в Сибири, температуре взбивания микропены молока 62°C, гиде по дрип-пакетам и концепции завтраков весь день.
   - Удобный модальный ридер с фотографиями и временем чтения.
6. **Авторизация и Профиль**:
   - Вход и регистрация.
   - Накопление бонусов («Зерна-бонусы»).
   - История заказов с возможностью в любой момент открыть и распечатать чек любого прошлого заказа.

### Для Администратора:
1. **Аналитика и визуализация данных (Chart.js)**:
   - 4 ключевые KPI-карточки (Общая выручка, Количество заказов, Средний чек, Выручка за сегодня).
   - Линейный график динамики выручки по дням за последние 7 дней.
   - Круговая диаграмма долей продаж по категориям (Кофе, Завтраки, Десерты...).
   - Столбчатый график пиковых часов нагрузки кофейни (утренний, обеденный, вечерний пики).
2. **Управление заказами**:
   - Таблица заказов в реальном времени.
   - Смена статусов: «Принят» -> «Готовится» -> «Готов к выдаче» -> «Выдан» -> «Отменен».
   - Просмотр чека любого заказа.
3. **Управление товарами (CRUD)**:
   - Добавление новых позиций с ценой, граммовкой, описанием, фото и категорией.
4. **Интеграция с 1С:Предприятие**:
   - Кнопка скачивания номенклатуры в формате **CommerceML 2.09 XML**.
   - Кнопка скачивания чеков и выручки в формате **EnterpriseData XML**.
5. **C++ Оптимизатор очередей**:
   - Кнопка live-запуска C++ алгоритма распределения нагрузки бариста.

## 🚀 Быстрый старт

### 1. Требования
- Python 3.10+
- ОС: Windows (для нативного C# компилятора `csc.exe`) или Linux/macOS (с автоматическим фоллбэком)

### 2. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 3. Компиляция C# модуля (Windows)
```bash
csharp_engine\build.bat
```
*(Или приложение скомпилирует его автоматически при первом запуске).*

### 4. Запуск веб-приложения
```bash
python run.py
```
После запуска откройте в браузере:
👉 **[http://127.0.0.1:8000](http://127.0.0.1:8000)**

### 5. Демо-аккаунты для мгновенного входа:
В модальном окне «Войти» доступны две кнопки быстрого входа в 1 клик:
- **👨‍💼 Администратор**: `admin@zerno.coffee` / пароль: `admin123`
- **☕ Гость кофейни**: `alex@zerno.coffee` / пароль: `guest123`
